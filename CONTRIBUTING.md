# Contributing to Wandernav

Thank you for helping improve Wandernav.

By submitting a contribution, you certify that you have the right to submit it and agree to license it under the project's [PolyForm Noncommercial License 1.0.0](LICENSE). Your contribution must not contain code or assets whose terms conflict with that license.

Please keep changes consistent with the project's priorities: ease of use, offline reliability, small size, fast startup, user privacy, and minimal dependencies.

Any new production dependency must satisfy the review described in [the dependency policy](docs/dependency-policy.md).
